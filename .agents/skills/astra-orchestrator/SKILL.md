# Astra Orchestrator Skill

When invoked, plan and orchestrate subagents:
- Use @explorer to map out dependencies, entry points, and existing conventions.
- Use @worker to perform code changes in targeted, manageable steps.
- Use @tester to run validation scripts or test suites.
- Use @reviewer to audit the final diff prior to completing the task.

# Esempi plugin

I file JSON di LaTeX e OCR sono workflow operativi, insieme agli esempi semplici. Timer e flashcard per Anki si attivano nel gestore come plugin integrati.

Le cartelle JavaScript e i pacchetti `.osiplugin` rappresentano il vecchio runtime, sospeso per sicurezza: non possono essere eseguiti né riattivati con un permesso. Il file JSON del vecchio Anki è conservato per compatibilità e consultazione. Vedi `PLUGIN_GUIDE.md` nella radice del repository.
